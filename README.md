# موقع محل الهواتف

موقع ثابت (HTML/CSS/JS) + Supabase + Vercel.

- `index.html`: المتجر (بانر متحرك، كتالوج، سلة، طلب عبر واتساب)
- `admin.html`: لوحة التحكم (/admin) — منتجات، طلبات، إعدادات
- `js/config.js`: رابط Supabase والمفتاح العام (publishable) فقط
- `js/home.js`: البانر المتحرك وأقسام الصفحة الرئيسية

## الأمان
- RLS مفعّل على كل الجداول. الزوار يقرؤون المنتجات الظاهرة فقط.
- الطلبات تُنشأ فقط عبر الدالة `place_order` (الأسعار تُقرأ من القاعدة، تحقق من المدخلات، حد 5 طلبات/ساعة لكل رقم).
- لوحة التحكم تقبل فقط الحسابات الموجودة في جدول `admin_users`.
- رؤوس أمان (CSP, HSTS, X-Frame-Options...) في `vercel.json`.
